# Cadash Z80 VBlank interrupt — 2026-10-14

The reported Cadash sound-driver hang is fixed. At frame2000 with the unchanged
USA/Korea cartridge and no controller replay, the old build has FM writes0 and
Z80 wait counter0x1FFF=3. The corrected build reaches counter0 and28038 FM port
writes. Unchanged Genesis Plus GX also reports counter0. This establishes driver
progress and register traffic; mdx does not yet synthesize audio. Final Z80 RAM
still differs in152 bytes, so this is not full sound-state or cycle equivalence.

## Source and implementation

Independent source: `cache/oracle/Genesis-Plus-GX/core/system.c:487–525` asserts
Z80 INT at the delayed VINT point, independently of the68000 VINT enable, and
clears it at the end of that scanline. The initial post-reset frame skips this
pulse. The existing H32/H40 VINT delays are770/788 master clocks after VBlank.

VDP now retains a separate `z80_irq` level. System advances devices in intervals
ending at a frame boundary, INT assertion or INT clear, so a large DMA/CPU wait
cannot collapse the finite pulse or latch it after BUSREQ/RESET holds. The signed
Z80 instruction budget still carries overshoot across those intervals. Scheduling
and device bus timestamps remain instruction granular; sub-instruction bus
arbitration is still incomplete.

Independent `core/z80/z80.c:3235–3298,3420–3436` supplies the related interrupt
rules corrected here: EI shadows the following instruction; interrupt entry
costs13T in IM0/IM1 and19T in IM2; the undriven IM0 bus suppliesFF/RST38; IM2
pushes the return PC before reading the indirect vector. Interrupt cycles are
counted once. External INT remains a level until the VDP clears it.

## Verification and state compatibility

Twenty-four capture cases from six authored cartridges cover IM0/IM1/IM2 × H32/H40 ×
frames1/2/3/6 against the unchanged independent core. All counters match0/1/2/5.
The portable fixture is `crates/mdcore/tests/fixtures/z80_vblank.json`; its source
and ROM hashes record provenance. `tools/probes/z80_vblank.py` reproduces it with
external oracle assets. Default regressions also cover EI/HALT/repeated EI,
interrupt stack/vector order and clock accounting, BUSREQ/RESET pulse expiry,
large waits across multiple frames, and save/load at both INT edges.

Machine-state format is now2 and includes the INT level and EI shadow. Format1
states are rejected because they represent the previous execution model; capture
fresh checkpoints. A fresh Cadash2700→4500 split run again matches uninterrupted
execution by full-state digest, all memory buffers and screenshot. Loaded boot,
trace and watch also reach identical state IDs.

Remaining work includes Z80 banked-bus contention, scheduler/device access phase,
two large active-VRAM DMA probes and the remaining live RAM differences. The user
requested sound synthesis after the current interrupt/timing work; offline

audio validation needed. No original oracle execution, commercial ROM, replay or
